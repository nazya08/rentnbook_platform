# Система RentnBook

**RentnBook** — це веб-додаток для управління орендою житла. Він надає функціонал як для орендарів, так і для власників житла, включаючи публікацію об’єктів, управління бронюваннями та збір відгуків. Мета системи — спростити процес оренди та покращити взаємодію для всіх користувачів.

## Основні можливості

1. **Реєстрація та створення профілю**  
   - Орендарі та власники житла можуть створювати профілі, заповнюючи необхідну інформацію.

2. **Пошук житла**  
   - Орендарі можуть шукати житло за різними критеріями: місцезнаходження, дати заїзду і виїзду, кількість гостей, тип житла та ціна.

3. **Перегляд деталей об'єкта**  
   - Орендарі можуть переглядати деталі житла: фотографії, опис, зручності, ціни та наявність.

4. **Бронювання**  
   - Орендарі можуть бронювати житло, заповнивши форму з зазначенням дат, кількості гостей та інших деталей.

5. **Підтвердження бронювання**  
   - Система надсилає запити на підтвердження як орендарям, так і власникам житла. Власники можуть підтвердити або відхилити бронювання.

6. **Управління житлом**  
   - Власники можуть переглядати активні бронювання та оновлювати інформацію про свої об'єкти.

7. **Збір відгуків**  
   - Після закінчення оренди орендарі можуть залишати відгуки, що допомагає іншим користувачам у виборі житла.

8. **Адміністрування**  
   - Адміністратори можуть аналізувати статистику використання платформи, відгуки та запити, щоб покращити функціонал і якість сервісу.

## Встановлення та використання

Інструкції для локального запуску проєкту для розробки та тестування.

### Налаштування

1. **Клонувати репозиторій:**
   ```bash
   git clone git@github.com:nazya08/rentnbook_platform.git
2. **Створити віртуальне середовище:**
    ```bash
   python -m venv venv
3. **Активувати віртуальне середовище:**
    - На Windows:
    ```bash
   cd venv/Scripts
    ./activate
   ```
   - На Linux або Mac:
    ```bash
   source venv/bin/activate
4. Створити та налаштувати файл .env.example:
    ```bash
   cp .env.example .env
   ```
5. **Встановити залежності:**
    ```bash
   cd rentnbook
    pip install -r requirements.txt
6. **Запустити проєкт:**
    - Виконати міграції:
    ```bash
   make migrate
   ```
   - Запустити сервер:
    ```bash
   make run
   ```
Після цього проєкт буде доступний локально за адресою http://127.0.0.1:8000/.
